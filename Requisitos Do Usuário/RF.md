# 1. Requisitos Funcionais

<p align="justify">A <i>Tabela 1</i> a seguir contém os Requisitos Funcionais (RF) elicitados utilizando a técnica de Brainstorm.</p>

| ID   | Requisito                                                                 | Prioridade | Requisitos Relacionados |
| :--: | :------------------------------------------------------------------------ | :--------: | :----------------------: |
| RF01 | Resposta em até 2 segundos. Um móvel por cadastro (itens individuais). Qualquer estado de conservação é permitido.                                               | Alta       | -                        |
| RF02 | Usuário acessa móveis que cadastrou (status "disponível") + móveis que salvou como favoritos.                          | Alta       | RF01                     |
| RF03 | Acesso separado por: disponíveis, em processo de doação, já doados (histórico).        | Baixa      | RF01                     |
| RF04 | Filtros combináveis: tipo, estado de conservação, tamanho, bairro.                                 | Média      | RF03                     |
