## Questões Atividade 09

▪ O que é Integração Contínua?  
## R: Integração Continua é uma prática de desenvolvimento de software em que os programadores mesclam suas alterações de código em um repositório central com frequência
▪ Qual é o papel das branches nesse processo?  
## R: As branches servem como ambientes isolados para o desenvolvimento seguro de novas funcionalidades ou correção de erros, sem interferir no código que já está funcionando
▪ Por que o Pull Request é importante?  
## R: Merge Request é importante porque ele funciona como a porta de segurança e o ponto de colaboração central antes que qualquer código novo seja misturado ao projeto principal.
